# design/ — UI デザイン（ビジュアル仕様）

Claude Design で作成した UI デザインのソース。**実装用のコードではなく、見た目と挙動の仕様書**として扱う。

| ファイル | 内容 |
|---|---|
| `Main.dc.html` | PC（1024px 以上）2 カラム。地図・フィルター・Random Pick!・抽選モーダルを含む |
| `SP.dc.html` | Tablet / SP（1024px 未満）1 カラム。地図の下にフィルター、下部固定ボタン、ボトムシート型モーダル |
| `canvas.json` | キャンバス上の配置情報（実装には不要） |
| `screenshots/` | （任意）各画面の PNG。キャンバスからエクスポートして置く |

## 読み方
- `.dc.html` は独自ランタイム（`support.js`、`<x-dc>`、`<sc-for>`、`<sc-if>`、`{{hole}}`）を使った形式。**そのままでは動かないし、コピーもしない。** Vue コンポーネントとして書き直すこと。
- 参考にするもの：色（カラーコード）、余白、角丸、枠線、影、フォントサイズ・太さ、レイアウト構造、文言、状態の変化（チェックの ON/OFF、0 件時、抽選後のハイライト、モーダル）。
- 下部の `<script>` 内のロジック（`SPOTS`、絞り込み、抽選）はデザイン確認用のダミー。仕様は CLAUDE.md を正とする。
- 地図部分（白い道路の div、% 座標のマーカー）は**イメージ図**。実装では MapLibre の実地図に置き換え、マーカー・凡例・ズームボタン・アトリビューションの見た目だけを再現する。
- モーダル内ルートの L 字線もダミー。実装では routing API の GeoJSON を描画する。
- インラインのカラーコードは実装時に `styles/tokens.css` の CSS 変数に置き換える。
- Lucide アイコンは SVG を直書きしているが、実装では `lucide-vue-next` のコンポーネントを使う。
